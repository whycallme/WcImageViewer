# Changelog

## v1.3.1

- 리스트뷰가 열린 상태에서 파일·폴더를 열면(다른 인스턴스 실행, 메뉴 열기) 리스트뷰 종료 처리로 메인창까지 닫히던 문제 수정
- 업데이트 확인을 앱 완전 종료 시점으로 통합: 뷰어·리스트뷰 전환 시에는 확인하지 않음, 종료 시 캐시된 릴리스 즉시 표시 또는 짧은 시간 제한 확인, 건너뛰기 버전·자동 확인 설정 반영, 리스트뷰 종료 시 메인창 깜빡임 제거, 업데이트 창 오류 시 종료 불능 수정

## v1.3.0

- "다른 이름으로 저장" 대화창 신규 (`SaveAsWindow`): 저장 형식 선택, 형식별 옵션 패널, JPEG·WebP 품질 슬라이더, 애니메이션 저장, 저장 전 예상 시간 확인, 저장 중 취소, Esc로 닫기
- 뷰어·리스트뷰·썸네일 우클릭 메뉴에 "다른 이름으로 저장" 연결
- 저장 형식 콤보 표시 개선 (`PNG (.png)` 형태)
- 저장창 생성 시 발생하던 NullReferenceException 수정 (슬라이더 초기화 순서)
- 빌드 중간 산출물을 프로젝트별 폴더로 분리 (`Directory.Build.props`, `build\obj\<프로젝트명>\`)

## v1.2.0

- 뷰어·리스트뷰에 새 폴더 만들기 추가 (툴바 버튼, 우클릭 메뉴, 기본 단축키 Ctrl+Shift+N, 이름 입력 창, 중복 이름 경고, 생성 후 새로고침)
- 뷰어·리스트뷰 우클릭 컨텍스트 메뉴 추가 및 메뉴 항목 오른쪽에 단축키 표시 (다크 테마 MenuItem 템플릿)
- 리스트뷰 우클릭 시 해당 썸네일 선택 후 메뉴 표시; 메뉴 정리 ('열기'는 선택 이미지를 뷰어로 열기, 썸네일 확대/축소 라벨, 의미 없던 창에 맞춤·100% 크기·이미지 정보 항목 제거)
- 빌드 산출물을 build/ 폴더(lite, portable)로 통일 (Directory.Build.props, scripts 경로)
- 리스트뷰 컨텍스트 메뉴에서 '이미지 정보' 항목 제거 (하단에 파일 정보가 이미 표시됨)

- 리스트뷰 종료(닫기/ESC) 시 업데이트 확인 및 업데이트 창 표시 추가
- v1.1.1: 리스트뷰 종료(닫기/ESC) 시 업데이트 확인 트리거 추가
