# WC Image Viewer v0.2.0

v0.2 업데이트입니다. WebP/AVIF/HEIC 지원과 100MP 초과 이미지 타일링, 애니메이션 개선을 포함합니다.

## 다운로드

| 파일 | 크기 | 요구사항 |
|---|---|---|
| `WcImageViewer-portable-win-x64.zip` | 약 59MB | 없음 (self-contained) |
| `WcImageViewer-lite-win-x64.zip` | 약 2.9MB | .NET 10 Desktop Runtime |

압축을 풀고 `WcImageViewer.exe`를 실행하세요. ZIP에는 `LICENSE`와 `THIRD-PARTY-NOTICES.md`가 함께 들어 있습니다.

## 새 기능

- WebP(애니메이션 포함), AVIF, HEIC/HEIF 읽기
- WebP/AVIF/HEIC/HEIF 파일 연결과 확장자 아이콘
- 100MP 초과 이미지 타일 디코딩
  - 4096px 미리보기 + 512px 타일
  - 레벨별 디코딩(원본 512 / 1,024 / 2,048px 영역), 32타일 LRU
  - EXIF 회전 상태에서도 타일 정렬
- 긴 애니메이션 WebP 재생
  - libwebp로 프레임을 순차 지연 디코딩
  - 640프레임·30fps 애니메이션 재생 확인
- GIF 투명 프레임 합성
  - WIC가 반환하는 변경 영역 프레임을 이전 캔버스 위에 합성
  - disposal(유지/배경 복원/이전 복원) 처리
  - 투명 영역이 어둡게 보이던 문제 수정
- Tab 정보 오버레이에 실시간 프레임 카운터 표시 (`프레임 9/27`)
- 작은 이미지는 확대하지 않음 옵션 (기본 켜짐)
  - 최소 창 크기(800×600)보다 작은 이미지를 100%로 표시
  - 창 맞춤·맞춤 모두에 적용

## 변경 및 수정

- 썸네일을 원본 전체 디코딩 대신 축소 디코딩으로 생성
- 애니메이션 WebP/GIF의 메모리 사용량 개선
- 애니메이션 프레임 디코딩 시간을 반영해 재생 간격 보정
- 사용이 끝난 애니메이션 디코더 정리
- 테스트 49개 통과

## 알려진 제한

- 코드 서명이 없어 Windows SmartScreen 경고가 표시될 수 있습니다.
- Inno Setup 설치본은 아직 제공하지 않습니다.
- 100MP 초과 이미지의 `다른 이름으로 저장`·클립보드 복사는 화면용 미리보기(최대 4096px)로 동작합니다.
- 애니메이션 AVIF, TIFF 다페이지 탐색, ICC 색 관리는 아직 지원하지 않습니다.
- HEIC/HEIF는 Microsoft Store의 **HEIF 이미지 확장**과 **HEVC 비디오 확장**이 필요합니다.

## 요구사항

- Windows 10/11 x64
- lite: .NET 10 Desktop Runtime
