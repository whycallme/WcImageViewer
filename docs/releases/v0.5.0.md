# WC Image Viewer v0.5.0

v0.5.0 adds support for opening an image that was extracted by Bandizip from an archive: the viewer now resolves the original archive from the Bandizip temporary folder and loads all images in that archive, so next/previous navigation works.

## 다운로드

| 파일 | 요구사항 |
|---|---|
| `WcImageViewer-portable-win-x64.zip` | 없음 (self-contained) |
| `WcImageViewer-lite-win-x64.zip` | .NET 10 Desktop Runtime |

ZIP은 파일 3개로 구성됩니다: `WcImageViewer.exe` (updater 내장), `LICENSE`, `THIRD-PARTY-NOTICES.md`.

## 주요 변경

- **Bandizip 임시 폴더 지원**: `%TEMP%\BNZ.*` 경로의 이미지를 열면 부모 프로세스(Bandizip) 명령줄에서 원본 아카이브를 찾아 해당 아카이브를 열고, 추출된 파일명에 해당하는 항목부터 탐색합니다.
- v0.4.4의 업데이터/업데이트 확인 수정 포함.
