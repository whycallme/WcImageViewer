# WC Image Viewer v1.0.0

v1.0.0은 폴더 이미지를 Enter로 열 수 있는 리스트뷰 창을 추가합니다. 왼쪽 위 폴더 트리, 왼쪽 아래 선택 이미지 큰 미리보기, 오른쪽 위 가상화 썸네일 목록, 오른쪽 아래 파일 정보로 구성되며, 다중 선택 삭제·복사·이동과 썸네일 크기·정렬 기준 설정(폴더별/전역 기억 선택)을 지원합니다. 지연 로딩으로 기본 뷰어의 시작·표시 속도에는 영향을 주지 않습니다.

## 다운로드

| 파일 | 요구사항 |
|---|---|
| `WcImageViewer-portable-win-x64.zip` | 없음 (self-contained) |
| `WcImageViewer-lite-win-x64.zip` | .NET 10 Desktop Runtime |

ZIP은 파일 3개로 구성됩니다: `WcImageViewer.exe` (updater 내장), `LICENSE`, `THIRD-PARTY-NOTICES.md`.

## 주요 변경

- **리스트뷰 창**: Enter로 열리는 4분할 창(폴더 트리 / 큰 미리보기 / 가상화 썸네일 목록 / 파일 정보)을 추가했습니다.
- **다중 선택 작업**: 썸네일 목록에서 다중 선택 후 삭제·복사·이동을 지원합니다.
- **썸네일 설정**: 썸네일 크기와 정렬 기준을 설정할 수 있으며, 폴더별 또는 전역으로 기억합니다.
- **지연 로딩**: 리스트뷰 관련 모듈은 필요할 때만 로드되어 기본 뷰어의 시작·표시 속도에 영향을 주지 않습니다.
- v0.5.1의 라이트 테마 배경 투명 수정 포함.
