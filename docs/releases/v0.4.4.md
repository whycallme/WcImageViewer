# WC Image Viewer v0.4.4

v0.4.4 includes two updater/update-check fixes.

## 다운로드

| 파일 | 요구사항 |
|---|---|
| `WcImageViewer-portable-win-x64.zip` | 없음 (self-contained) |
| `WcImageViewer-lite-win-x64.zip` | .NET 10 Desktop Runtime |

ZIP은 파일 3개로 구성됩니다: `WcImageViewer.exe` (updater 내장), `LICENSE`, `THIRD-PARTY-NOTICES.md`.

## 주요 변경

- **업데이터 롤백 수정**: 새 앱이 15초간 살아있는지 확인하던 방식을 UI 준비(WaitForInputIdle) 확인으로 변경. 업데이트 직후 창을 닫아도 롤백되지 않으며, 실제 시작 실패 시에만 이전 버전으로 복원합니다.
- **업데이트 확인 개선**: 보류 중인 업데이트가 있을 때 24시간 캐시를 무시하고 다시 확인하여, 캐시된 중간 버전에 머무르지 않고 최신 버전으로 바로 업데이트합니다.
- v0.4.3의 정리/리팩터링 변경 포함.
