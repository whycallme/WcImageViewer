# WC Image Viewer v0.5.1

v0.5.1은 라이트 테마에서 파일을 열 때 창 배경이 가끔 투명하게 보이던 버그를 수정합니다. DWM 창 속성 적용을 첫 렌더 이후로 옮기고 재그리기를 추가했습니다.

## 다운로드

| 파일 | 요구사항 |
|---|---|
| `WcImageViewer-portable-win-x64.zip` | 없음 (self-contained) |
| `WcImageViewer-lite-win-x64.zip` | .NET 10 Desktop Runtime |

ZIP은 파일 3개로 구성됩니다: `WcImageViewer.exe` (updater 내장), `LICENSE`, `THIRD-PARTY-NOTICES.md`.

## 주요 변경

- **라이트 테마 시작 시 배경 투명 수정**: 파일을 열면 창 배경이 가끔 그려지지 않던 문제를 해결했습니다. DWM 창 속성 적용을 첫 렌더 이후로 옮기고 재그리기를 추가했습니다.
