# WC Image Viewer v0.4.0

v0.4 업데이트입니다. 앱이 새 버전을 스스로 확인하고, 종료할 때 업데이트 창을 띄워 다운로드·검증·교체까지 처리합니다. 기존 기능과 단축키는 그대로 유지합니다.

> **v0.3.0 이하에서 올라오는 경우 이번 v0.4.0은 한 번만 수동으로 설치해야 합니다.** 자동 업데이트 코드가 v0.4.0에 처음 들어갔기 때문에, v0.3.0 이하에는 스스로를 갱신할 방법이 없습니다. 아래 ZIP을 내려받아 압축을 풀고 `WcImageViewer.exe`를 덮어쓰면 되고, **v0.4.0 이후 버전부터는 자동 업데이트가 동작합니다.**

## 다운로드

| 파일 | 크기 | 요구사항 |
|---|---|---|
| `WcImageViewer-portable-win-x64.zip` | 62,188,029 B (약 62MB) | 없음 (self-contained) |
| `WcImageViewer-lite-win-x64.zip` | 3,091,627 B (약 3MB) | .NET 10 Desktop Runtime |

압축을 풀고 `WcImageViewer.exe`를 실행하세요. ZIP에는 파일 4개가 들어 있습니다.

- `WcImageViewer.exe`
- `WcImageViewer.Updater.exe` (교체용 네이티브 updater)
- `LICENSE`
- `THIRD-PARTY-NOTICES.md`

## 주요 변경

- **자동 업데이트 확인** — 시작 3초 후 GitHub 릴리즈를 확인하고, 새 버전이 있으면 설정 아이콘에 점을 표시합니다. 24시간 안에 확인한 기록이 있으면 다시 확인하지 않으며, 설정에서 자동 확인을 끌 수 있습니다.
- **종료할 때 업데이트 창** — 새 버전이 확인된 상태로 창을 닫으면 업데이트 창이 뜹니다. 반디집처럼 "지금 업데이트하고 종료", "그냥 종료", "이 버전 건너뛰기" 중에서 고를 수 있습니다.
- **다운로드와 검증** — 릴리즈에 공개된 ZIP 크기와 SHA-256 digest를 그대로 검증하고, 진행률과 취소를 지원합니다. 검증에 실패하면 앱은 그대로 유지되고 오류 로그 경로를 보여 줍니다.
- **네이티브 updater** — `WcImageViewer.Updater.exe`(.NET Framework 4.8, 별도 설치 불필요)가 앱 종료 후 파일을 교체하고 새 버전을 실행합니다. 교체에 실패하면 이전 파일로 되돌립니다.
- **업데이트 창 가독성** — GitHub 릴리즈 본문의 Markdown 문법(`##`, 표, 백틱, 링크)을 제거한 평문으로 표시합니다.
- **설정 > 업데이트** — 현재 버전, 자동으로 업데이트 확인, 지금 확인, 마지막 확인 시각, 건너뛴 버전과 "다시 알림" 버튼을 제공합니다.

## 동작 방식

1. 앱이 시작되면(자동 확인이 켜져 있을 때) 24시간에 한 번 새 릴리즈를 확인합니다.
2. 새 버전이 있으면 설정 아이콘에 점이 표시되고, 설정 > 업데이트에서 내용을 볼 수 있습니다.
3. 창을 닫으면 업데이트 창이 뜹니다. **업데이트하고 종료**를 고르면 ZIP 다운로드 → 크기·SHA-256 검증 → updater 실행 → 앱 종료 순서로 진행됩니다.
4. **그냥 종료**는 지금 버전으로 종료하고 다음 실행 때 다시 알립니다. **이 버전 건너뛰기**는 그 버전을 건너뛰며, 설정에서 **다시 알림**을 누르면 해제됩니다.

## 최초 수동 부트스트랩

- v0.3.0 이하 → v0.4.0: **한 번 수동 설치가 필요합니다.** ZIP을 풀어 기존 폴더에 덮어쓰면 됩니다.
- v0.4.0 이후 → 다음 버전: 자동 업데이트가 동작합니다.

## 요구사항

- Windows 10/11 x64
- lite: .NET 10 Desktop Runtime
- 업데이트 적용에는 .NET Framework 4.8(Windows 10 1903 이상에 기본 포함)

## 알려진 제한

- Windows 10은 DWM 라운드 모서리를 지원하지 않아 창 모서리가 사각형으로 표시됩니다.
- 시스템 `MessageBox`는 네이티브 Windows 스타일을 유지합니다.
- 코드 서명이 없어 Windows SmartScreen 경고가 표시될 수 있습니다.
- Inno Setup 설치본은 아직 제공하지 않습니다.
- 100MP 초과 이미지의 `다른 이름으로 저장`·클립보드 복사는 화면용 미리보기(최대 4096px)로 동작합니다.
- 앱이 설치된 폴더에 쓰기 권한이 없으면 업데이트 적용이 실패할 수 있습니다(Program Files 등). portable 배포는 사용자 폴더에 두는 것을 권장합니다.
