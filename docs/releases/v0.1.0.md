# WC Image Viewer v0.1.0

첫 공개 릴리즈입니다. Windows 10/11 x64에서 설치 없이 실행할 수 있습니다.

## 다운로드

| 파일 | 크기 | 요구사항 |
|---|---|---|
| `WcImageViewer-portable-win-x64.zip` | 약 59MB | 없음 (self-contained) |
| `WcImageViewer-lite-win-x64.zip` | 약 2.4MB | .NET 10 Desktop Runtime |

압축을 풀고 `WcImageViewer.exe`를 실행하세요.

## 주요 기능

- JPEG, PNG, BMP, GIF(애니메이션), TIFF, ICO
- ZIP/CBZ, 7Z/CB7, RAR/CBR 읽기와 고체 압축 진행률 표시
- 폴더/이미지/압축파일 드래그 앤 드롭
- 이전/다음, 썸네일 스트립, 전체화면, 슬라이드쇼
- 슬라이드쇼 반복·랜덤 재생
- 파일 끝에서 `첫 파일로 가기` / `아무것도 안 하기` 선택
- 경계에서 “첫 파일입니다.” / “마지막 파일입니다.” 중앙 알림 (선택)
- 커서 기준 줌, 드래그 팬, 맞춤/100%, 표시 배율 직접 입력
- EXIF orientation, GIF 애니메이션, 다크 테마, High-DPI
- 이름 바꾸기, 삭제(확인/휴지통), 편집 앱 열기, 클립보드 복사, 다른 이름으로 저장
- 책갈피, 최근 항목, 단축키 변경, 확장자별 파일 연결
- 여러 창 / 하나의 창으로 열기 선택
