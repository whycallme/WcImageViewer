# WC Image Viewer v0.4.2

v0.4.2는 배포를 **updater 없는 3파일 ZIP**으로 정리한 릴리즈입니다. updater는 앱 exe에 내장되어 있고, 배포 폴더에는 `WcImageViewer.exe`와 문서 2개만 남습니다.

> **v0.4.1 이상에서 올라오면 자동으로 업데이트됩니다.** v0.4.0 이하는 v0.4.2를 한 번 수동으로 설치해야 합니다. v0.4.0 이하의 업데이트 코드는 ZIP 안의 `WcImageViewer.Updater.exe`를 요구하는데 v0.4.2 ZIP에는 없기 때문입니다. **updater가 들어간 마지막 ZIP은 v0.4.1입니다.** v0.3.0 이하는 자동 업데이트 코드가 없어 어느 버전이든 한 번은 수동 설치가 필요합니다.

## 다운로드

| 파일 | 크기 | 요구사항 |
|---|---|---|
| `WcImageViewer-portable-win-x64.zip` | 62,189,153 B (약 62MB) | 없음 (self-contained) |
| `WcImageViewer-lite-win-x64.zip` | 3,091,805 B (약 3MB) | .NET 10 Desktop Runtime |

압축을 풀고 `WcImageViewer.exe`를 실행하세요. ZIP에는 파일 3개가 들어 있습니다.

- `WcImageViewer.exe` (updater 내장)
- `LICENSE`
- `THIRD-PARTY-NOTICES.md`

별도의 `WcImageViewer.Updater.exe`는 ZIP에도, 압축을 푼 폴더에도 없습니다. 업데이트할 때 앱이 내장 updater를 `%TEMP%\WcImageViewer\run-<guid>\`에 풀어 실행합니다.

## 주요 변경

- **3파일 ZIP** — `scripts/publish.ps1`이 updater를 csc로 컴파일해 앱 exe에 임베드하기만 하고, 게시 폴더에 복사하지 않습니다. ZIP은 `WcImageViewer.exe`, `LICENSE`, `THIRD-PARTY-NOTICES.md` 3개 엔트리입니다. 스크립트가 ZIP 엔트리 수·updater 부재·임베드 리소스·FileVersion을 검사합니다.
- **배포 폴더 정리** — 이전 빌드가 `publish\portable`, `publish\lite`에 남긴 updater를 게시 전에 삭제합니다. v0.4.1에서 올라온 폴더도 첫 실행 시 앱이 옆의 updater를 지워 exe 하나만 남깁니다.
- **자동 업데이트 유지** — v0.4.1+ 앱은 ZIP에 updater가 없어도 내장 updater로 다운로드·크기/SHA-256 검증·파일 교체를 수행합니다. v0.4.1 → v0.4.2 자동 업데이트를 portable/lite 모두 실제로 검증했습니다.
- **업데이트 피드** — 공개 저장소(`whycallme/WcImageViewer`)의 최신 릴리즈 API를 그대로 사용합니다. v0.4.1에서 저장소 공개 전환으로 해결된 404 상태가 유지되며, 이번 릴리즈도 같은 피드에서 정상 조회됩니다.
- **문서** — README/PLAN/release notes를 3파일 ZIP과 버전 호환성 기준으로 갱신했습니다.

## 동작 방식 (v0.4.1 → v0.4.2)

1. v0.4.1 앱이 시작 3초 후 공개 피드에서 v0.4.2를 확인하고 설정 아이콘에 점을 표시합니다.
2. 창을 닫으면 업데이트 창이 뜨고, **업데이트하고 종료**를 고르면 3파일 ZIP 다운로드 → 크기·SHA-256 검증 → 내장 updater 실행 → 앱 종료 순서로 진행됩니다.
3. updater가 새 exe와 문서를 교체하고 v0.4.2를 실행합니다. ZIP에 updater가 없으므로 폴더에 updater를 복사하지 않습니다.
4. 폴더에는 `WcImageViewer.exe`, `LICENSE`, `THIRD-PARTY-NOTICES.md`만 남습니다.

## 요구사항

- Windows 10/11 x64
- lite: .NET 10 Desktop Runtime
- 업데이트 적용에는 .NET Framework 4.8(Windows 10 1903 이상에 기본 포함)

## 알려진 제한

- Windows 10은 DWM 라운드 모서리를 지원하지 않아 창 모서리가 사각형으로 표시됩니다.
- 시스템 `MessageBox`는 네이티브 Windows 스타일을 유지합니다.
- 코드 서명이 없어 Windows SmartScreen 경고가 표시될 수 있습니다.
- Inno Setup 설치본은 아직 제공하지 않습니다.
- 100MP 초과 이미지의 `다른 이름으로 저장`·클립보드 복사는 화면용 미리보기(최대 4096px)로 동작합니다.
- 앱이 설치된 폴더에 쓰기 권한이 없으면 업데이트 적용이 실패할 수 있습니다(Program Files 등). portable 배포는 사용자 폴더에 두는 것을 권장합니다.
