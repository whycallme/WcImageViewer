# WC Image Viewer v0.3.0

v0.3 업데이트입니다. 메인 창 외관을 28px 한 줄 커스텀 크롬으로 개편하고, 플로팅 썸네일 도크와 라이트/다크 테마를 추가했습니다. 기존 기능과 단축키는 그대로 유지합니다.

## 다운로드

| 파일 | 크기 | 요구사항 |
|---|---|---|
| `WcImageViewer-portable-win-x64.zip` | 62,167,108 B (약 62MB) | 없음 (self-contained) |
| `WcImageViewer-lite-win-x64.zip` | 3,069,759 B (약 3MB) | .NET 10 Desktop Runtime |

압축을 풀고 `WcImageViewer.exe`를 실행하세요. ZIP에는 `WcImageViewer.exe`, `LICENSE`, `THIRD-PARTY-NOTICES.md`가 들어 있습니다.

## 주요 변경

- **28px 한 줄 커스텀 창 크롬** — Windows 기본 타이틀바와 툴바를 한 줄로 합쳤습니다. 왼쪽에 앱 아이콘·파일명·`i / N` 이미지 개수 칩, 오른쪽에 아이콘 툴바와 최소화/최대화/닫기 버튼이 있습니다. Windows 11에서는 작은 라운드 모서리와 테마에 맞는 테두리 색을 사용합니다.
- **라이트/다크 테마** — 은은한 베이지 계열 라이트 테마를 추가했습니다. 설정 > 일반 > 테마에서 즉시 전환되며, 취소하면 원래 테마로 돌아가고, 다시 시작해도 선택이 유지됩니다. 대화상자, 메뉴, 툴팁, 스크롤바까지 같은 팔레트를 따릅니다.
- **74px 플로팅 썸네일 도크** — 하단 전체 폭 스트립 대신 이미지 위에 떠 있는 도크로 바꿨습니다. 기본 숨김, 하단 호버·`T`로 표시, 선택/호버/휠 스크롤 동작은 기존과 같습니다.
- **대화상자 통일** — Settings/Bookmark/Rename에 28px 커스텀 타이틀바를 적용하고 ComboBox/CheckBox/ScrollBar/ContextMenu/ToolTip을 공용 테마 컨트롤로 맞췄습니다.
- **Tab 정보 오버레이 가독성 개선** — 어두운 반투명 배경 위에 밝은 텍스트를 표시해 밝은 이미지에서도 읽을 수 있습니다.
- 기존 이미지 탐색, 압축파일, 슬라이드쇼, 책갈피, 이름 바꾸기, 삭제, 파일 연결, 단축키를 그대로 유지합니다.

## 요구사항

- Windows 10/11 x64
- lite: .NET 10 Desktop Runtime

## 알려진 제한

- Windows 10은 DWM 라운드 모서리를 지원하지 않아 창 모서리가 사각형으로 표시됩니다.
- 시스템 `MessageBox`는 네이티브 Windows 스타일을 유지합니다.
- 코드 서명이 없어 Windows SmartScreen 경고가 표시될 수 있습니다.
- Inno Setup 설치본은 아직 제공하지 않습니다.
- 100MP 초과 이미지의 `다른 이름으로 저장`·클립보드 복사는 화면용 미리보기(최대 4096px)로 동작합니다.
