# WC Image Viewer v0.4.3

v0.4.3 is a cleanup and refactor release on top of v0.4.2. No user-facing feature changes; update is optional but recommended for the internal improvements.

## 주요 변경

- **디자인 시안 제거**: 사용하지 않던 `design/` 아이콘/UI 시안과 생성 스크립트를 저장소에서 제거.
- **디렉터리 정리 공용화**: `UpdateInstaller`/`UpdateService`의 중복 `TryDeleteDirectory`를 `DirectoryCleanup`으로 통합.
- **이미지 소스 인터페이스 정리**: `IImageSource`에 `CreateReopenFactory`/`GetFilePath`를 추가하고 `FolderImageSource`/`ArchiveImageSource`가 구현. `MainWindow`가 타입 캐스팅 대신 인터페이스 메서드를 사용.
- **테마 브러시 정리**: 오버레이/알림 색을 `DarkTheme.xaml` 브러시 리소스로 추출하고 `MainWindow.xaml`에서 참조. 닫기 버튼 스타일 중복 제거.
- **게시 프로파일 정리**: 공통 게시 속성을 `publish-common.props`로 추출.
- **테스트 정리**: 임시 폴더 생성을 `TestTemp` 헬퍼로 통일. 테스트 94개 통과.
