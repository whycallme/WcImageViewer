# WC Image Viewer v0.4.1

v0.4.0의 자동 업데이트를 바로잡는 후속 패치입니다. 업데이트 확인이 404로 실패하던 원인(비공개 저장소)을 공개 전환으로 해결했고, 배포 폴더에 따로 있던 `WcImageViewer.Updater.exe`를 앱 exe에 내장해 **첫 실행 후 폴더에 `WcImageViewer.exe` 하나만** 남깁니다.

> v0.4.0 사용자는 이번 버전부터 자동 업데이트로 올라올 수 있습니다. v0.3.0 이하는 자동 업데이트 코드가 없어 한 번만 수동으로 설치해야 합니다.

## 다운로드

| 파일 | 크기 | 요구사항 |
|---|---|---|
| `WcImageViewer-portable-win-x64.zip` | 62,194,121 B (약 62MB) | 없음 (self-contained) |
| `WcImageViewer-lite-win-x64.zip` | 3,096,221 B (약 3MB) | .NET 10 Desktop Runtime |

압축을 풀고 `WcImageViewer.exe`를 실행하세요. ZIP에는 v0.4.0에서 올라오는 한 번의 업데이트를 위한 파일 4개가 들어 있습니다.

- `WcImageViewer.exe` (updater 내장)
- `WcImageViewer.Updater.exe` (v0.4.0 호환용, 첫 실행 후 삭제)
- `LICENSE`
- `THIRD-PARTY-NOTICES.md`

## 주요 변경

- **업데이트 404 해결** — 저장소를 public으로 전환했습니다. 자동/수동 업데이트 확인이 공개 릴리즈 피드에서 정상 동작합니다.
- **404 안내 개선** — 그래도 피드를 찾지 못하면 "업데이트 피드를 찾을 수 없습니다. 저장소가 비공개이거나 릴리즈가 없습니다. (404)"라고 설정 상태와 로그에 표시합니다.
- **updater 내장** — `WcImageViewer.Updater.exe`를 앱 exe의 리소스로 넣었습니다. 업데이트할 때 `%TEMP%\WcImageViewer\run-<guid>\`에 풀어 실행하며, 다운로드한 ZIP에 updater가 없어도 됩니다.
- **배포 폴더 정리** — 내장 updater가 있는 빌드는 시작할 때 앱 옆의 `WcImageViewer.Updater.exe`를 삭제합니다. v0.4.0에서 올라온 폴더와 `publish\lite` 폴더가 첫 실행 후 exe 하나가 됩니다. (이전 updater가 아직 실행 중이면 잠금이 풀릴 때까지 재시도하고, 실패는 무시합니다.)
- **ZIP 호환** — v0.4.0 앱은 ZIP 안의 updater를 요구하므로, v0.4.1 ZIP에는 v0.4.0 호환용 updater를 한 번 더 넣었습니다. v0.4.2부터는 ZIP에서 updater를 빼고 `WcImageViewer.exe` + 문서 2개, 3개 엔트리로 배포할 예정입니다.
- **업데이트 확인 우선순위** — 실행할 updater는 ① 앱에 내장된 것 → ② 설치 폴더의 updater(구버전·개발 빌드) → ③ ZIP 안의 updater 순서로 고릅니다. 모두 없으면 명확한 오류를 냅니다.

## 동작 방식

1. v0.4.0 앱이 시작 3초 후 공개 피드에서 v0.4.1을 확인하고 설정 아이콘에 점을 표시합니다.
2. 창을 닫으면 업데이트 창이 뜨고, **업데이트하고 종료**를 고르면 ZIP 다운로드 → 크기·SHA-256 검증 → updater 실행 → 앱 종료 순서로 진행됩니다.
3. updater가 새 exe와 문서를 교체하고 v0.4.1을 실행합니다. v0.4.1은 시작하면서 옆의 호환용 updater를 지워 폴더를 정리합니다.
4. 실패하면 이전 exe로 되돌리고 오류와 로그 경로를 보여 줍니다.

## 요구사항

- Windows 10/11 x64
- lite: .NET 10 Desktop Runtime
- 업데이트 적용에는 .NET Framework 4.8(Windows 10 1903 이상에 기본 포함)

## 알려진 제한

- Windows 10은 DWM 라운드 모서리를 지원하지 않아 창 모서리가 사각형으로 표시됩니다.
- 시스템 `MessageBox`는 네이티브 Windows 스타일을 유지합니다.
- 코드 서명이 없어 Windows SmartScreen 경고가 표시될 수 있습니다.
- Inno Setup 설치본은 아직 제공하지 않습니다.
- 100MP 초과 이미지의 `다른 이름으로 저장`·클립보드 복사는 화면용 미리보기(최대 4096px)로 동작합니다.
- 앱이 설치된 폴더에 쓰기 권한이 없으면 업데이트 적용이 실패할 수 있습니다(Program Files 등). portable 배포는 사용자 폴더에 두는 것을 권장합니다.
