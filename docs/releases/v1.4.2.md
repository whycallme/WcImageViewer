## v1.4.2

- 설정 "편집 앱"에 "그림판" 버튼 추가: Windows 기본 그림판(mspaint.exe)을 이름만으로 지정 (WindowsApps 별칭 경로는 찾아보기로 선택 시 권한 오류). 이름만 있는 값은 파일 존재 검사 없이 실행.
- 리스트뷰에서도 "편집 앱으로 열기"(Ctrl+E, 우클릭 메뉴) 지원: 여러 개 선택 시 맨 앞 1개만 연다.
- 리스트뷰에서 여러 이미지를 선택해 인쇄 가능: 이미지마다 1페이지, 인쇄 미리보기에 페이지 이동(◀ N / M ▶, PageUp/PageDown·휠).
- 여러 장 인쇄 시 서로 다른 사진이 같은 사진으로 반복 인쇄되던 문제 수정 (XPS 직렬화기가 이미지를 한 리소스로 합치던 것을 이미지별 복사본으로 회피). X/Y DPI가 다른 이미지도 픽셀 비율을 유지해 인쇄.
